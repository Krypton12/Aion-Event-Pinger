# Aion-Event-Pinger
Discord Bot that pings roles for Events on Aion 2 based on static time without use of API key.
!status for curConfig,
!setchannel in Channel to set the pinging Channel,
!setrift @Role to set pinging role,
!setshugo @Role to set pinging role,
!setsiege @Role to set pinging role.

For setup Change Token to own Discord bot token in bot.py.
Dockerfile and requirements setup for fly hosting.
